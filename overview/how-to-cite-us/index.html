How to cite us

If you used Neurodesk in your research or teaching, please cite our main paper and the relevant containerised tools to ensure reproducibility and proper attribution.

Citing Neurodesk

Section titled “Citing Neurodesk”

Please cite the Neurodesk paper. You can also access it via the open access link or refer to the preprint version.

If you used Neurodesktop, please include the version used (e.g. v2026-11-20). See examples below.

Full citation: Renton, A.I., Dao, T.T., Johnstone, T., Civier, O., Sullivan, R. P., White, D. J., … Narayanan, A. & Bollmann, S. Neurodesk: an accessible, flexible and portable data analysis environment for reproducible neuroimaging. Nat Methods (2024). https://doi.org/10.1038/s41592-023-02145-x

Citing specific tools

Section titled “Citing specific tools”

For reproducibility, include the tool name, version number, and build date for each containerised application that you used in Neurodesk. Also cite the original publications for each tool, as well as Neurodesk. You can get this information in two ways:

  • Copy the citation from the Applications catalogue for one tool.
  • Run neurodesk cite in Neurodesktop to get a citation list for all the tools that you loaded.

Where available, the Container DOI link in the application list identifies the packaged software version on Zenodo. Cite that record to identify your computational environment, and cite the tool papers to credit the underlying methods.

Citing EEG/MEG related tools

If you used any EEG/MEG/electrophysiology tools, please also cite the AEDAPT project.

Copy a citation from the Applications catalogue

Section titled “Copy a citation from the Applications catalogue”

Each card in the Applications catalogue has a Tool citations row. If the tool’s recipe has a citation, the row shows it, and DOIs and URLs in it are links. The row has these buttons:

  • Copy citation copies the tool’s citation text. It appears only when the tool has a citation.
  • Copy methods text copies a methods sentence for the latest version of the tool, followed by a reference list with the tool’s citation and the Neurodesk paper.

If a tool has no citation in the catalogue, find the tool’s directory in neurocontainers/recipes and look for references in README.md or the readme section of build.yaml. Follow the tool authors’ guidance for the methods you used. For example, the FSL recipe includes overview references and directs readers to the individual tools’ manuals.

Generate a citation list with neurodesk cite

Section titled “Generate a citation list with neurodesk cite”

Neurodesktop records each Neurodesk tool that you load. The neurodesk cite command turns that record into a CITATIONS.md file with a methods sentence for each tool version and one reference list.

Note

Neurodesktop releases after 2026-09-23 record tool loads. Use neurodesk-cite in images that do not have the neurodesk CLI yet. Older images do not record tool loads.

What Neurodesktop records

Section titled “What Neurodesktop records”

Neurodesktop adds one line to a usage log each time a Neurodesk module loads. The line has the module name, the version, and the time in UTC. Loads from these places are recorded:

  • ml and module load in a terminal.
  • Notebook kernels and the module side panel in JupyterLab.
  • Applications in the desktop menu.

The log is ~/.local/state/neurodesk/module-usage.tsv, or $XDG_STATE_HOME/neurodesk/module-usage.tsv if you set XDG_STATE_HOME. Only Neurodesk modules from CVMFS or from local containers are recorded. The log stays only in your home directory, and Neurodesktop does not send it anywhere. Your home directory is persistent in the standard Docker and hosted setups, so the log is kept when you restart Neurodesktop.

Use neurodesk cite offline

Section titled “Use neurodesk cite offline”

neurodesk cite downloads the catalogue each time it runs and keeps a copy in ~/.cache/neurodesk/. If the download fails, the command uses the copy and prints the date of the copy. If there is no copy, the command still writes CITATIONS.md, but without build dates or tool citations, and it prints a warning.

For tool maintainers

Section titled “For tool maintainers”

The citation for each tool comes from its recipe in neurocontainers, recipes/<tool>/build.yaml. Neurodesk uses structured_readme.citation if the recipe sets it. Otherwise, it uses the Citation: section of the readme. The Applications catalogue and neurodesk cite read the citation from the catalogue data, so a change to the citation does not need a container rebuild. To add or fix a citation, open a pull request in neurocontainers that changes build.yaml.
